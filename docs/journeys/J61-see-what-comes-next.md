# J61 See what comes next in a new project
*Source: #451 — a new project with a video and a data file in it showed the picture with nothing
drawn on it, and nothing on screen said gauges came next. The checklist that did was the last
section of the project's inspector, below the fold, and gave way to the new file's inspector as
soon as the file was added.*

1. **File ▸ New**, and add a video: a bar above the preview says *Next step: Add the data*, what
   that means, and **Add Data File…**.
2. Each step done moves it on — the data lined up with the video, gauges (**Apply the Classic Dash
   Template**), then Export, ticked once a video has been exported.
3. **Show All Steps** clears the selection and shows the whole **Getting Started** checklist, now
   first in the project's inspector.
4. The bar's ✕ hides it and the checklist; **Help ▸ Show Getting Started** brings them back.

Tests: `GettingStartedUITests.testANewProjectSaysWhatComesNext`, `FirstLaunchUITests`.

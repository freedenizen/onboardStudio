# J50 From a session to a debrief
*Source: #397 — the things a driver wants from a session in the logbook, a debrief video and a
comparison with the best they have done here, each needed a project set up by hand first.*

1. Select a session in the Logbook. **Compare With ▸** lists the logbook's other sessions at
   the circuit — **Personal Best Here** and **Last Visit** first, then every one by date and car.
   Choose one: the Coaching window opens on the session with that reference already chosen, lined
   up by position, as it would be from a project; the choice is kept with the session.
2. **Export Coaching Debrief…** (there once the session has a clip on its day) opens a project
   from the session — its data file, its clips, the Coaching Debrief layout — with the debrief
   sheet up, ready to read the corners and export. The project is yours to keep or close.
3. **Coach…**, **New Project** and the rest sit beside them, so every way out of a session is one
   click from its row.

Tests: `LogbookActionsUITests.testASessionIsComparedAndDebriefedFromTheLogbook`. Model:
`LogbookReferencesTests`, `LogbookTests`.
